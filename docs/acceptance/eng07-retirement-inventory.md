## Classification rule

Retire **execution semantics 1/2**, compatibility admission/read unions and old user journeys from the active product. Do not delete a current fence, durable receipt or wire contract because its identifier contains `oneShot`, `V1`, `v2` or `repeat`. Execution semantics, graph protocol version, repeat contract version, provider API version and ordinary workflow revision are independent.

This is a **source-backed, targeted inventory of observed exports and current boundaries**, not a claim of a repository-wide zero-match scan. The current engine, authoring, inspector and Board paths were inspected together with the existing retirement guards. The table distinguishes directly observed residue from boundaries covered by test definitions. Transitive import closure, every bootstrap/fixture and a fresh-profile browser network trace must be checked by the retirement implementation/gate; they were not executed here. No historical compatibility reader is thereby declared supported.
